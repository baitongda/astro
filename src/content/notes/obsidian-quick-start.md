## 一句话结论

Obsidian 不需要一开始就安装大量插件。先把本地仓库、笔记属性、双链和搜索用起来，再根据实际需求扩展，知识库才有机会长期生长。

## 最小启动路径

1. 从 [Obsidian 官网](https://obsidian.md) 安装桌面版或移动版。无需注册账号也能使用。
2. 新建 Vault。Vault 本质上是一个本地文件夹，所有笔记都以 Markdown 文件保存，数据不被平台锁定。
3. 新建笔记时先写 frontmatter，例如标题、日期、标签和状态。后续检索、分类和自动化都会用到这些属性。
4. 用 `[[笔记名称]]` 建立双向链接。链接到目标笔记后，可以在目标页看到反链；没有显式创建链接时，笔记名称被提及时也可能被识别为潜在链接。
5. 不熟悉菜单时使用命令面板。它比记快捷键更适合入门阶段。

## 核心功能

### Vault 与本地文件

- 一个 Vault 对应一个普通文件夹。
- 笔记使用 Markdown 保存，可以自由备份和迁移。
- 如果使用 Mac，可以把 Vault 放在 iCloud 等同步目录中；也可以使用 Git 管理版本。

### 双向链接

```md
[[另一篇笔记]]
[[另一篇笔记|自定义显示名称]]
[[另一篇笔记#某个标题]]
[[另一篇笔记^某个段落]]
```

双向链接的价值不只是跳转，而是让零散笔记逐渐形成可以检索的关系网络。

### 嵌入内容

```md
![[另一篇笔记]]
![[另一篇笔记#某个标题]]
![[另一篇笔记^某个段落]]
```

在链接前加 `!`，就能把整篇笔记、指定标题或指定段落嵌入当前页面。

## Markdown 速查

```md
# 一级标题
**加粗**
*斜体*
~~删除线~~
==高亮==
- 无序列表
1. 有序列表
- [ ] 待办事项
> 引用
> [!NOTE]
> 标注块
```

表格可以通过命令面板搜索“插入表格”完成，不必手动记忆复杂格式。

## 插件建议

### 建议先启用的核心插件

- **工作区**：保存和切换常用布局。
- **白板**：梳理结构、做思维发散。
- **关系图谱**：观察笔记之间的连接和知识结构。
- **模板**：复用统一的笔记结构。

### 按需安装的第三方插件

- **Iconize**：为文件夹增加图标。
- **Link Favicons**：为外部链接显示站点图标。
- **Novel Word Count**：统计文件夹内的笔记数量和字数。
- **Number Headings**：自动给多级标题编号。
- **Excalidraw**：在笔记中插入手绘草图。
- **Git**：自动提交、拉取和推送笔记版本。

插件不要一次性装齐。先出现明确需求，再找对应工具。

## 常用快捷键

- `Command/Ctrl + O`：快速切换笔记。
- `Command/Ctrl + P`：打开命令面板。
- 其他操作可以在“设置 → 快捷键”中搜索并自定义。

## 实践建议

- 先选一个真实主题建 5 到 10 篇笔记，不要先设计庞大的分类体系。
- 每篇笔记至少写清楚标题、摘要和标签。
- 用双链连接相关概念，不急着追求漂亮的关系图谱。
- 每使用一段时间再调整结构，让系统在实践中逐步稳定。
